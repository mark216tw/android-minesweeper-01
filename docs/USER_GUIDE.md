# 踩地雷使用指南

## 安裝

1. 前往本專案的 GitHub Releases 頁面。
2. 下載最新 Pre-release 的 `app-prerelease.apk`。
3. 在 Android 裝置上開啟 APK。
4. 若系統阻擋安裝，依畫面指示允許該來源安裝未知應用程式。
5. 完成後啟動「踩地雷」。

Pre-release APK 使用 Debug 金鑰簽署，僅供測試。若未來正式版本改用正式金鑰，可能需要先移除測試版才能安裝。

## 基本規則

- 每個數字表示周圍八格內的地雷數量。
- 點按未開啟格子可探索該格。
- 長按未開啟格子可插旗或取消旗幟。
- 第一個探索格及其周圍九宮格不會放置地雷。
- 開啟全部非地雷格即可獲勝。
- 點到地雷即失敗。
- 棋盤可能出現需要猜測的局面。

## 難度

| 難度 | 棋盤 | 地雷 |
|---|---:|---:|
| 初級 | 9 × 9 | 10 |
| 中級 | 16 × 16 | 40 |
| 高級 | 30 × 16 | 99 |
| 自訂 | 寬 5–30、高 5–24 | 使用者設定 |

新遊戲對話框會顯示各標準難度的個人最佳勝利時間。沒有進行中的棋局時，預設開啟中級棋盤。

## 遊戲結果

- 結果視窗會顯示難度、棋盤尺寸、地雷數、遊戲時間與剩餘悔棋次數。
- 勝利時會顯示該難度的最佳時間，刷新紀錄時標示「新紀錄！」。
- 遊戲進行中會保持螢幕亮著，避免自動休眠。

## 棋盤操作

### 探索

點按未開啟且未插旗的格子。若該格周圍沒有地雷，遊戲會自動展開相連的安全區域。

### 插旗

- 長按格子可插旗，再次長按可取消。
- 開啟「插旗」模式後，點按格子會改為插旗或取消旗幟。
- 旗幟只是玩家標記，不會改變地雷位置。

### 快速展開

當已開啟數字周圍的旗幟數與數字相同時，點擊該數字可展開其餘相鄰格。若旗幟位置錯誤，快速展開仍可能踩到地雷。

### 縮放與移動

- 使用雙指手勢縮放棋盤。
- 放大後可拖曳棋盤。
- 大型棋盤會以較容易點按的比例開始，必要時可縮小或拖曳查看全盤。
- 點擊「置中」可恢復適合畫面的比例與位置。

## 自訂棋盤

1. 點擊「新遊戲」。
2. 選擇「自訂棋盤」。
3. 調整寬度、高度及地雷數量。
4. 點擊「開始」直接遊玩，或點擊「儲存設定」保存組合。

最多可保存 3 組自訂棋盤：

- 點擊已保存項目可套用設定。
- 重複的組合不會再次保存。
- 滿 3 組後需先刪除一組才能新增。
- 已保存項目可個別刪除；刪除前會再次確認。

## 主畫面功能

- 紀錄圖示：開啟遊戲紀錄。
- 分享畫面圖示：將目前遊戲畫面截圖並開啟 Android 系統分享面板。
- 全螢幕圖示：切換全螢幕模式。
- 齒輪圖示：開啟 APP 設定。
- 表情按鈕：重新開始相同難度。
- 插旗：切換點按插旗模式。
- 置中：重設棋盤縮放及位置。
- 新遊戲：選擇標準難度或自訂棋盤。

## 悔棋

- 踩到地雷時，可在結果視窗選擇悔棋，按鈕會顯示剩餘次數。
- 悔棋次數依難度不同：初級 1 次、中級 2 次、高級 3 次、自訂 3 次。
- 悔棋會恢復踩雷前的棋盤與旗幟，並從當時的時間繼續遊戲。
- 次數用完後再次踩雷即無法復原。
- 悔棋後，該次踩雷不會保留在失敗紀錄中。
- 結果視窗顯示期間只會顯示踩中的地雷；關閉視窗後才揭露其他地雷與錯旗。

## 外觀設定

### 主介面版型

- 經典版：沿用 Windows 踩地雷的傳統儀表與操作列，為預設版型。
- 復古掌機版：棋盤占用較大空間，使用 A 插旗、B 置中與 START 新遊戲的掌機控制盤。
- 切換版型會立即生效並自動保存，不會中斷或重建目前棋局。
- 復古掌機版在直式使用底部控制盤，橫式使用右側控制盤。

### 顯示模式

- 系統：跟隨 Android 系統外觀。
- 淺色：固定使用淺色介面。
- 深色：固定使用深色介面。
- 狀態列與導覽列會跟隨目前的復古風格與明暗模式變色。

### 復古風格

- Windows 灰：固定天空藍配色，保留經典 3D 浮雕。
- Windows 灰綠：Windows 灰搭配經典綠選取色。
- 麥金塔：黑白單色、方正邊框與單色棋盤。
- Game Boy 綠：DMG 四色綠、像素斜邊與點陣質感。
- Commodore 64：VIC-II 藍底淺藍字，PETSCII 雙線框。
- 紅白機：奶油機殼配 NES 紅，純黑硬像素描邊。
- Apple II 綠幕：P1 磷光綠單色、掃描線與扁平外框。
- 每種風格皆提供淺色與深色變體，可由「外觀模式」切換。
- 風格會套用到經典版與復古掌機版，操作按鈕位置不變。
- 不再提供自訂主題色或色相滑桿。

### 音效與震動

- 「遊戲音效」控制翻格、插旗與勝敗音效。
- 「震動回饋」控制翻格、插旗與勝敗震動。
- 「預設插旗模式」決定新遊戲是否預設使用點按插旗。

## 遊戲紀錄

遊戲會保存以下結果：

- 勝利：綠色勾選標籤。
- 失敗：紅色地雷標籤。
- 放棄：橘色離開標籤。

每筆紀錄包含難度、棋盤尺寸、地雷數、遊戲時間及日期。可複製文字摘要或呼叫 Android 系統分享面板。

- 可使用「全部／勝利／失敗／放棄」快速篩選紀錄。
- 每筆紀錄可個別刪除，刪除前會再次確認。
- 「清除全部紀錄」會刪除所有結果，但不影響 APP 設定及目前棋局。

## 資料保存

- APP 進入背景時會保存目前棋局並暫停計時。
- 返回 APP 後可繼續遊戲。
- 關閉 APP 或被系統回收不會記錄為放棄。
- 主動開始其他棋局時，目前已開始的棋局會記錄為放棄。

## 疑難排解

### 無法安裝 APK

確認 Android 已允許目前使用的瀏覽器或檔案管理器安裝未知來源應用程式。

### 新版本安裝失敗

測試版若使用不同簽署金鑰，Android 不允許直接覆蓋安裝。請先移除舊版，再重新安裝；移除 APP 會同時刪除本機紀錄與設定。

### 回報問題

請在 GitHub Issues 提供：

- Android 版本
- 手機型號
- APP 版本
- 重現步驟
- 預期與實際結果
