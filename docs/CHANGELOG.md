# 變更紀錄

本文件記錄「踩地雷」的重要版本變更。

## [1.4.2-prerelease] - 2026-10-31

### 新增

- 主畫面右上角、遊戲紀錄圖示右側新增「分享畫面」圖示，可將目前遊戲畫面截圖並透過 Android 系統分享面板分享。
- 沒有進行中的棋局時，預設開啟中級棋盤。

### 改進

- 移除結果視窗的分享選項與原有「分享結果」文字分享，分享功能統一由主畫面圖示提供。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.4.1-prerelease] - 2026-10-30

### 改進

- 系統狀態列與導覽列會跟隨目前復古風格與明暗模式變色。
- 關閉導覽列對比覆蓋，避免三鍵導覽列出現與畫面不一致的底色。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。
- 本版彙整 1.2.0～1.4.0 的累積變更，完整說明請見 `docs/RELEASE_NOTES.md`。

## [1.4.0-prerelease] - 2026-10-30

### 新增

- 新增「麥金塔」復古風格，套用於經典版與復古掌機版，提供淺色與深色單色變體。
- 麥金塔風格使用方正黑白邊框、單色棋盤、單色數字與黑白七段顯示器。
- 設定頁新增「復古風格：Windows 灰／麥金塔」。

### 改進

- 移除主題色預設與色相滑桿，Windows 灰風格固定使用天空藍。
- 麥金塔風格維持黑白單色，不套用天空藍強調色。
- 遊戲紀錄的勝敗標籤在麥金塔風格下改為單色呈現。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.3.1-prerelease] - 2026-10-30

### 改進

- 移除經典版與復古掌機版右上角的離開按鈕，主畫面只保留紀錄、全螢幕與設定。
- 系統 Home 鍵與返回鍵行為維持不變。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.3.0-prerelease] - 2026-10-30

### 新增

- 結果視窗顯示難度、棋盤、地雷、時間、最佳時間與新紀錄提示，並可直接分享結果。
- 新遊戲對話框顯示各標準難度的個人最佳時間。
- 遊戲紀錄新增「全部／勝利／失敗／放棄」篩選與單筆刪除。
- 翻格、插旗、勝利及失敗皆支援震動回饋。
- 遊戲進行中會保持螢幕亮著。

### 改進

- 經典版與掌機版都會顯示目前難度與棋盤尺寸；經典版狀態列補上「剩餘地雷」與「時間」標示。
- 深色模式改用高對比數字配色。
- 大型棋盤初始以較易點按的比例顯示，平板等大螢幕也能自動放大。
- 自訂棋盤刪除加入二次確認。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.2.1-prerelease] - 2026-10-30

### 改進

- 修正快速重新開始或關閉結果視窗時，棋局存檔可能亂序造成進度遺失的問題。
- 以本地圖示取代 extended icons，移除該依賴，並為 release 建置啟用 R8 與資源壓縮。
- 改善棋盤縮放、拖曳與快速操作時的手勢穩定度。
- 主題色滑桿改為即時預覽、停止拖曳後才寫入設定。
- 設定讀取失敗時改用預設值，避免啟動失敗。
- 系統列改用 Edge-to-edge 設定，移除已棄用的系統列顏色 API。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.2.0-prerelease] - 2026-10-30

### 改進

- 悔棋次數改為依難度調整：初級 1 次、中級 2 次、高級 3 次、自訂 3 次。
- 結果視窗的悔棋按鈕會顯示剩餘次數。
- 資料庫升級至 version 3，保留既有棋局並轉換悔棋使用次數。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。

## [1.1.1-prerelease] - 2026-10-09

### 改進

- 踩雷結果視窗顯示期間只顯示踩中的地雷，關閉後再揭露完整失敗棋盤與錯旗。

### 發布狀態

## [1.1.0-prerelease] - 2026-09-28

### 新增

- 踩雷後可使用一次「悔棋(限一次)」恢復上一個操作。
- 悔棋支援直接踩雷與快速展開踩雷。

### 改進

- 悔棋會恢復踩雷前的棋盤、旗幟及計時，並移除該次失敗紀錄。
- 使用 Room transaction 保持失敗紀錄與進行中棋局一致。
- 新增資料庫 migration，升級時保留既有棋局與歷史紀錄。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。
- APK 啟用 R8 與資源壓縮，使用 Android Debug 金鑰簽署。

## [1.0.0-prerelease] - 2026-09-06

### 新增

- 經典 Windows 風格踩地雷棋盤。
- 初級、中級、高級及自訂難度。
- 最多 3 組自訂棋盤儲存、套用及刪除。
- 點按探索、長按插旗、插旗模式與快速展開。
- 棋盤縮放、拖曳及置中。
- 直式、橫式與全螢幕模式。
- 系統、淺色、深色外觀及主題色設定。
- 經典版與復古掌機版主介面切換。
- 主畫面提供將 APP 切換至背景的離開按鈕。
- 進行中棋局自動保存。
- 勝利、失敗及放棄紀錄與差異化標籤。
- 結果複製、分享及清除全部紀錄。
- 離線運作，無廣告及追蹤。

### 改進

- 將棋盤狀態與顯示時間分離，減少計時期間不必要的棋盤重組與重繪。
- 快取棋盤數字繪製資料，降低大型棋盤的繪製負擔。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。
- APK 啟用 R8 與資源壓縮，使用 Android Debug 金鑰簽署。
