# 變更紀錄

本文件記錄「踩地雷」的重要版本變更。

## [1.0.0-prerelease] - 2026-09-06

### 新增

- 經典 Windows 風格踩地雷棋盤。
- 初級、中級、高級及自訂難度。
- 最多 3 組自訂棋盤儲存、套用及刪除。
- 點按探索、長按插旗、插旗模式與快速展開。
- 棋盤縮放、拖曳及置中。
- 直式、橫式與全螢幕模式。
- 系統、淺色、深色外觀及主題色設定。
- 經典版與復古掌機版主介面切換。
- 進行中棋局自動保存。
- 勝利、失敗及放棄紀錄與差異化標籤。
- 結果複製、分享及清除全部紀錄。
- 離線運作，無廣告及追蹤。

### 改進

- 將棋盤狀態與顯示時間分離，減少計時期間不必要的棋盤重組與重繪。
- 快取棋盤數字繪製資料，降低大型棋盤的繪製負擔。

### 發布狀態

- 本版本為 Pre-release 測試版本，不是正式上線版本。
- APK 啟用 R8 與資源壓縮，使用 Android Debug 金鑰簽署。
