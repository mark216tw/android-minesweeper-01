# 踩地雷 1.5.0 Pre-release

本版是 1.1.1 之後的累積更新，整理如下。

## 本次亮點

- 復古風格擴充為七種：新增 Game Boy 綠、Commodore 64、紅白機、Apple II 綠幕與 Windows 灰綠，各有淺色與深色變體與專屬邊框語言。
- 提升 Commodore 64 淺色模式的文字對比；紅白機綠色數字一併微調。
- 沒有進行中的棋局時，預設開啟中級棋盤。
- 主畫面右上角新增「分享畫面」圖示，可直接分享目前遊戲畫面截圖；結果視窗不再提供分享選項。
- 新增「麥金塔」復古風格，套用於經典版與復古掌機版，提供淺色與深色單色變體。
- Windows 灰風格固定使用天空藍，移除主題色與色相滑桿設定。
- 系統狀態列與導覽列會跟隨復古風格與明暗模式變色。
- 移除主畫面右上角的離開按鈕，只保留紀錄、分享、全螢幕與設定。
- 悔棋次數改為依難度調整：初級 1 次、中級 2 次、高級 3 次、自訂 3 次。
- 結果視窗顯示難度、棋盤、地雷、時間、最佳時間與新紀錄提示。
- 新遊戲對話框顯示各標準難度最佳時間。
- 遊戲紀錄支援全部／勝利／失敗／放棄篩選與單筆刪除。
- 翻格、插旗、勝利與失敗支援震動回饋，遊戲進行中保持螢幕亮著。
- 大型棋盤初始以較易點按的比例顯示，平板等大螢幕也能自動放大。

## 修正與底層改善

- 修正快速重新開始或關閉結果視窗時，棋局存檔可能亂序造成進度遺失的問題。
- 改善棋盤縮放、拖曳與快速操作時的手勢穩定度。
- 移除 extended icons 依賴，release 建置啟用 R8 與資源壓縮。
- DataStore 讀取失敗時改用預設值，避免啟動失敗。
- 系統列改用 Edge-to-edge 設定，並讓顏色跟隨目前風格。
- 深色模式使用高對比數字配色；麥金塔風格使用單色棋盤與顯示器。
- 自訂棋盤與單筆紀錄刪除加入二次確認。

## 注意事項

- 本版本為 Pre-release 測試版本，不是正式上線版本。
- APK 使用 Android Debug 金鑰簽署；若無法覆蓋安裝，請先移除舊版再安裝。
- 設計稿與實作的細部色盤可能仍有調整空間，歡迎回報視覺問題。
